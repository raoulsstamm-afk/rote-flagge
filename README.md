# Rote Flagge

Beweis-Tagebuch gegen Beziehungen, die verunsichern. Vorfälle einsprechen oder tippen, Datum kommt automatisch, nach ein paar Wochen zeigt die App das Muster. Dazu "Schreib's hier statt ihm": Nachrichten 24 Stunden parken und ein Kontaktpause-Zähler. Alles bleibt nur auf dem Handy.

Stand: MVP (klickbarer Prototyp, Paywall nur Optik, keine KI, kein Server).

## Starten
```
npm install
npx expo start
```

## Prüfen
```
npx tsc --noEmit
npm run web-export
npm run screenshots   # Fotos aller Bildschirme nach docs/screenshots/
```
